# Документация по реализации нейронной сети

## Обзор
Этот код реализует нейронную сеть для оценки шахматных позиций с вычислениями на CPU с использованием NumPy. Сеть использует прямую архитектуру с одним скрытым слоем и включает оптимизатор Adam для обучения.

## Классы

### NetworkError
Пользовательский класс исключений для обработки специфических ошибок нейронной сети.

### Adam
Реализует алгоритм оптимизации Adam для градиентного спуска.

#### Параметры:
- `count`: Количество групп параметров для оптимизации
- `alpha`: Скорость обучения (по умолчанию: 0.001)
- `beta1`: Экспоненциальная скорость затухания для первого момента (по умолчанию: 0.9)
- `beta2`: Экспоненциальная скорость затухания для второго момента (по умолчанию: 0.999)
- `eps`: Малая константа для численной стабильности (по умолчанию: 1e-8)

### Network
Основной класс нейронной сети, реализующий архитектуру и методы обучения.

#### Параметры:
- `N`: Размер скрытого слоя
- `M`: Размер входного слоя (768 бит для представления позиции)
- `L`: Количество обучающих образцов
- `weight_type`: Тип данных для весов
- `input_type`: Тип данных для входных данных
- `output_type`: Тип данных для выходных данных
- `in_bord`: Граница отсечения скрытого слоя (α)
- `out_bord`: Граница отсечения выходного слоя (β)
- `weight_board`: Граница отсечения весов

#### Архитектура сети:
1. Входной слой (M нейронов)
2. Скрытый слой (N нейронов)
3. Выходной слой (1 нейрон)

#### Основные методы:

##### Управление данными:
- `read_db(in_f)`: Читает обучающие данные из JSON файла
- `read_coefs(coefs)`: Загружает веса сети из JSON файла
- `create_coefs()`: Инициализирует веса случайным образом
- `result()`: Сохраняет обученные веса в JSON файл

##### Прямое распространение:
- `Z()`: Вычисляет выход скрытого слоя
- `T()`: Вычисляет выходные веса на основе активного цвета
- `F()`: Вычисляет выход сети
- `E()`: Вычисляет ошибку

##### Обучение:
- `grad()`: Вычисляет градиенты для всех весов
- `update(optim)`: Обновляет веса используя оптимизатор Adam
- `upgrade()`: Отсекает веса для предотвращения переполнения
- `norm()`: Вычисляет L2 норму градиентов

## Формат данных

### Входные данные (JSON):
```json
{
    "count": float,    // Ожидаемое значение оценки
    "color": "w"/"b",  // Активный цвет (белый/черный)
    "fen": int        // Представление позиции
}
```

### Данные весов (JSON):
```json
{
    "A": array,     // Веса скрытого слоя
    "B": array,     // Смещение скрытого слоя
    "C_1": array,   // Выходные веса для белых
    "C_2": array,   // Выходные веса для черных
    "d": array      // Выходное смещение
}
```

## Обработка ошибок
- Комплексная проверка входных параметров
- Пользовательские исключения NetworkError
- Логирование ошибок с подробными сообщениями

## Математические формулы

1. Скрытый слой: Z = clip(AX + B, -α, α)
2. Выходные веса: T = X₂C₁ᵀ + (1-X₂)C₂ᵀ
3. Выход сети: F = clip((Z⊙T)1ₙ + d1ₗ, -β, β)
4. Ошибка: E = (Y-F)⊙M_F

## Зависимости
- numpy
- logging
- json

## Пример использования
```python
# Инициализация сети
net = Network(N=256, M=768, L=1000, ...)

# Загрузка или создание весов
net.create_coefs()
# или
net.read_coefs("weights.json")

# Загрузка обучающих данных
net.read_db("training_data.json")

# Инициализация оптимизатора
optimizer = Adam(count=5)

# Цикл обучения
net.grad()
net.update(optimizer)
net.upgrade()

# Сохранение результатов
net.result()
```
