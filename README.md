## Архитектура нейронной сети

### Структура сети
- **Входной слой**: 768 бинарных нейронов (представление шахматной позиции)
- **Скрытый слой**: 1024 нейрона с ограниченной ReLU-активацией [-6, 6]
- **Выходной слой**: 1 нейрон с ограничением [-32000, 32000]

### Математическая модель

#### Основные компоненты
- X₁: L×M матрица входных позиций
- X₂: L×1 вектор активного цвета
- A: M×N матрица весов скрытого слоя
- B: 1×N вектор смещения скрытого слоя
- C₁, C₂: N×1 векторы выходных весов для белых/черных
- d: скалярное выходное смещение

#### Расширенное математическое описание
##### Матричные операции
- Произведение входного слоя и весов: H = X₁A ∈ ℝᴸˣᴺ
- Добавление смещения: H' = H + B ∈ ℝᴸˣᴺ
- Активация: Z = clip(H', -α, α) ∈ ℝᴸˣᴺ
- Выбор весов по цвету: T = X₂C₁ + (1-X₂)C₂ ∈ ℝᴸˣ¹
- Финальный выход: F = clip(Z·T + d, -β, β) ∈ ℝᴸˣ¹

##### Градиентные формулы
∂E/∂A = X₁ᵀ(δh) ∈ ℝᴹˣᴺ
∂E/∂B = Σᵢ(δh)ᵢ ∈ ℝ¹ˣᴺ
∂E/∂C₁ = (X₂ᵀZ)ᵀδy ∈ ℝᴺˣ¹
∂E/∂C₂ = ((1-X₂)ᵀZ)ᵀδy ∈ ℝᴺˣ¹
∂E/∂d = Σᵢ(δy)ᵢ ∈ ℝ

#### Прямое распространение
1. Скрытый слой: Z = clip(X₁A + B, -α, α)
2. Выходные веса: T = X₂C₁ + (1-X₂)C₂
3. Выход сети: F = clip(Z·T + d, -β, β)

### Функция активации
В скрытом слое используется ReLU (Rectified Linear Unit):
```
f(x) = max(0, x)
f'(x) = {
    1, x > 0
    0, x ≤ 0
}
```

#### Расширенное описание ReLU
f(x) = {
    x,  x > 0
    0,  x ≤ 0
}

Производная в точке x = 0 не определена, используется субдифференциал:
∂f(0) ∈ [0, 1]

### Функция потерь
E(θ) = ½||Y - F||² - среднеквадратичная ошибка

#### Расширенная формула потерь
E(θ) = ½Σᵢ(yᵢ - f(θ; xᵢ))² + λ||θ||²
где λ||θ||² - L2-регуляризация

## Оптимизация и обучение

### Алгоритм оптимизации
- Используется алгоритм Adam с адаптивным шагом обучения
- Градиентный спуск с L2-нормализацией
- Отсечение весов для предотвращения переполнения

### Параметры обучения
- α = 6 (граница отсечения скрытого слоя)
- β = 32000 (граница отсечения выхода)
- η = c/||∇E(θ)||₂ (адаптивный шаг)

### Оптимизация Adam
Используется оптимизатор Adam со следующими гиперпараметрами:
- β₁ = 0.9 (коэффициент для первого момента)
- β₂ = 0.999 (коэффициент для второго момента)
- ε = 1e-8 (параметр стабилизации)

#### Формулы обновления Adam
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²
m̂ₜ = mₜ/(1-β₁ᵗ)
v̂ₜ = vₜ/(1-β₂ᵗ)
θₜ = θₜ₋₁ - η·m̂ₜ/(√v̂ₜ + ε)

### Регуляризация
Применяются следующие техники регуляризации:
1. Отсечение активаций скрытого слоя при |x| > α
2. Ограничение выходного значения сети диапазоном [-β, β]
3. L2-регуляризация весов с коэффициентом λ = 1e-5

#### Математическое описание регуляризации
R(θ) = λ(||A||² + ||B||² + ||C₁||² + ||C₂||² + d²)
E_total(θ) = E(θ) + R(θ)

### Вычисление градиентов
Градиенты вычисляются методом обратного распространения ошибки:
1. Прямой проход:
```
h = f(Ax + B)
y = C₁ᵀh + d (для белых)
y = C₂ᵀh + d (для черных)
```

2. Обратный проход:
```
δy = y - t
δh = C₁δy ⊙ f'(h) (для белых)
δh = C₂δy ⊙ f'(h) (для черных)
```

3. Градиенты:
```
∇A = xδhᵀ
∇B = δh
∇C₁ = hδy (для белых)
∇C₂ = hδy (для черных)
∇d = δy
```

## Форматы данных и использование

### Входные данные (JSON)
```json
{
    "count": float,    // Оценка позиции
    "color": "w"/"b",  // Активный цвет
    "fen": int         // Битовое представление позиции
}
```

### Веса сети (JSON)
```json
{
    "A": array,     // Веса скрытого слоя
    "B": array,     // Смещение скрытого слоя
    "C_1": array,   // Выходные веса (белые)
    "C_2": array,   // Выходные веса (черные)
    "d": array      // Выходное смещение
}
```

### Пример использования
```python
net = Network(N=1024, M=768, L=1000)
net.read_db("training_data.json")
net.create_coefs()  # или net.read_coefs("weights.json")
optimizer = Adam(count=5)

while True:
    net.grad()
    net.update(optimizer)
    net.upgrade()
```
